# 公网中继扩展方案（未实现）

需求「随时随地查看」不在当前版本里。当前版本只支持**手机和车机在同一 WiFi**。
这份文档说明怎么扩到公网，以及为什么现在不做。

---

## 为什么现在不做

| 原因 | 说明 |
| --- | --- |
| 需要一台常开服务器 | 中继必须 7×24 在线，否则「随时」不成立 |
| 免费证书撑不住 | 免费 Apple ID 证书 **7 天过期**，接了真实后端后 App 会周期性消失。要买开发者账号（688/年） |
| 车机在 NAT 后面 | 4G 下的车机没有公网 IP，必须让车机**主动外连**中继 |
| 局域网版还没验证 | 先把「能看见画面」这条链路跑通，再谈远程 |

---

## 好消息：两端协议一行都不用改

`docs/PROTOCOL.md` 里的视频流就是**普通 TCP 字节流**。所以中继可以做成一个
纯 TCP 代理，对两端完全透明：

```
手机端 ──TCP──> 中继服务器 ──TCP──> 车机端
                 （按 ticket 配对）
```

帧头格式、控制消息 JSON、手机端 UI 全部不变。

---

## 要新增的东西（只有三处）

### 1. 中继服务器

一台常开的 Linux 小机器（最便宜的 VPS 就够，带宽是唯一成本）。

职责只有两件：
- **发 ticket**：手机端请求 `POST /ticket` → 返回 `{ ticket, relayHost, relayPort }`
- **配对转发**：车机和手机端连上来报同一个 ticket，之后纯粹搬字节

```text
车机端 ──外连──> 中继 :9000   第一行：CAR  <ticket>
手机端 ──外连──> 中继 :9000   第一行：PHONE <ticket>
中继收到配对成功的两边 → 双向 pipe
```

**不要在中继里转码**。转码会把一个纯 TCP 代理变成一台需要 GPU 的机器，
而且两端已经商量好了 H.264 参数，没有转码的必要。

### 2. 车机端：加一个「中继模式」

现状是车机端开 `ServerSocket` 等人连。中继模式反过来：

- 车机端主动 `connect(中继, 9000)`，发 `CAR <ticket>`
- 之后所有控制/视频连接都走这条隧道复用（或者每路视频各开一条隧道连接）
- 断线重连 + 心跳

**关键**：摄像头枚举、编码、帧格式这些**完全不动**，只把「socket 对端」
从「手机」换成「中继」。

### 3. 手机端：把「直连 IP」换成「中继地址 + ticket」

`CarClient.connect(to:)` 现在吃的是一个 `CarDevice`（host + port）。
中继模式下 host 换成中继地址，并在第一条控制连接里带上 ticket。
发现逻辑从「收 UDP 广播」换成「拉一次服务器上的设备列表」。

## 带宽账（必须先算）

4 路 720p30 × 2.5 Mbps ≈ **10 Mbps 持续上行**。

| 场景 | 上行 | 结论 |
| --- | --- | --- |
| 车机用家里 WiFi | 100 Mbps+ | 随便看 |
| 车机用 4G（通常 10~30 Mbps） | 勉强 | 建议降到 480p / 1.5 Mbps，或只看 1~2 路 |
| VPS 按流量计费 | 10 Mbps × 86400 s ≈ **108 GB/天** | 流量费会很吓人，先算钱 |

> 建议中继版默认**只推 1 路（前视）**，用户在手机端手动切其他路。
> 这一个决定能把流量成本降到 1/4。

---

## 延迟预期

| 路径 | 预期延迟 |
| --- | --- |
| 同一 WiFi 直连（当前版本） | 80~200 ms |
| 公网中继（同城） | 200~400 ms |
| 公网中继（跨省） | 400~800 ms |

用的是 TCP 而不是 UDP/RTP，所以弱网下表现为「卡一瞬」而不是「花屏」。
真要做到 300 ms 以下的公网低延迟，得在协议里加 UDP 前向纠错 —— 那是另一件事了。

---

## 安全（别跳过）

当前协议是**明文的**，局域网内可接受，公网绝对不行：

1. 控制通道和视频流都套 TLS（中继自己做 terminate，或端到端）
2. ticket 一次性 + 短有效期（建议 60 秒）+ 绑定手机账号
3. 车机端用设备证书鉴权，别让谁都能来配对
4. 限速：单 ticket 的并发连接数和总带宽都要封顶

## 实现顺序建议

1. 先买开发者账号，把免费证书 7 天的问题解决掉
2. 局域网版装机验证通过（能看到画面、能切摄像头）
3. 写中继服务器 + 车机端中继模式，**先只做 1 路**
4. 手机端加「远程设备」入口，和局域网设备列表分开
5. 稳定后再考虑加多路和录像
